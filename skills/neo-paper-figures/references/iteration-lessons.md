# Lessons from actual figure revisions

| Problem observed | Revision that helped |
|---|---|
| Large empty panels with only module names | Add small concrete map/evidence/candidate examples, then reduce panel padding |
| Reader drawn before relation analysis | Put the two branches above/below, sharing input and merging into Judger |
| Many arrows crossing or making long detours | Separate forward flow and perimeter feedback; shorten the main path |
| All text competing for attention | One title size, one smaller label size; move explanations to visible examples |
| Generic network diagram | Show why edges differ: inherited, propagated, corrected, independent |
| Judger appears to generate one final sentence | Show an explanation population and keep/revise/reject transitions |
| Motivation image too wide for one column | Recompose panels vertically and inspect at column size |
| Cropped slide hard to paste into another PPT | Restore full slide dimensions while retaining the compact artwork |
| Attractive figure overstates the implementation | Mark it conceptual and distinguish current code from proposed mechanism |

Use the user's reference for visual vocabulary and density. Do not copy another
paper's distinctive artwork or claim its diagram as our own. The gallery contains
our project outputs, not the third-party reference figures.
